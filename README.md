# GranaryVault

Stellar-native treasury management and financial governance platform.

## Tech Stack

- **Framework:** Next.js 16 (App Router) + TypeScript
- **UI:** Material UI v9
- **Blockchain:** Stellar + Soroban Smart Contracts
- **Wallet:** Freighter

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
